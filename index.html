02 / What we build

Two ways to automate Revit.

pyRevit buttons handle the repeatable one-click tasks, and AI-powered MCP handles the queries and conditional logic. Both are built to your firm's specific standards.

Custom pyRevit buttons

One-click tools that integrate directly into your Revit interface. Best when the task is the same every time.

  • Bulk parameter updates on 100+ elements
  • Sheet naming and numbering automation
  • Room data sync from CSV
  • BIM standards compliance audits
  • Intelligent view management
Runs within your Revit environment. Model content and project files are never accessed or transmitted. License management collects session and tool-use data for seat tracking — full details in our data disclosure.

AI-powered MCP system

Natural-language Revit control via Claude. Best when inputs vary, conditional logic is required, or you want plain English commands.

  • Conversational queries across the model
  • Conditional element operations
  • Real-time problem solving in plain English
  • Excel / CSV data integration
  • Runs in the background; keep working in other apps while it processes
Your model content is never accessed or stored. No file paths, geometry, or project data is transmitted. Full details are available in our data disclosure.
